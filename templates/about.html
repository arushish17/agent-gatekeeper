Three-Tier Architecture

Design Pattern
1. Presentation Tier

Responsive web interface built with modern semantic HTML5, custom utility CSS3, and asynchronous JavaScript (AJAX). Enforces dark navy visual branding with Wells Fargo red accents.

2. Application & Decision Tier

Lightweight Flask controller routing incoming HTTP requests and mediating between web forms and decision_engine.py. Implements the 8 security policies in strict precedence order.

3. Persistence & Audit Tier

Zero-cloud local storage managed by storage.py. Retains registered agents in agents.json and immutable access records in audit_logs.json across server restarts.

Regulatory Context: Wells Fargo Precedent

American Banker

As reported by American Banker, Wells Fargo pioneered banking security requirements mandating that customers maintain verifiable proof when revoking access for third-party AI agents.

Without verifiable revocation records, banks remain exposed to unauthorized debit disputes under federal consumer protection statutes (Electronic Fund Transfer Act / Regulation E).

⚖️ Regulatory Resolution: When an administrator clicks Revoke in Agent Gatekeeper, the system transitions the agent status to REVOKED, records an immutable timestamp, logs the event to audit_logs.json, and blocks all future transactions under Rule 2.
