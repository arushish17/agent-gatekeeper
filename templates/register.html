Registration Governance

Wells Fargo Policy

Why Explicit Registration is Mandatory

In traditional web banking, APIs distinguish between authenticated users and anonymous visitors. With AI agents, the autonomous model holds delegated credentials. Rule 1 strictly blocks any unregistered agent to thwart credential-stuffing bots from executing unauthorized inquiries.

Preventing Zombie Access

Every registered agent receives a permanent record. If the customer later stops using the agent, the administrator or customer must use the Revoke Agent interface to invalidate the agent's credentials permanently.

Audit Trail Compliance

The registration event itself is timestamped and recorded in audit_logs.json to ensure non-repudiation and accountability under banking regulations.
